# 基本１０ヶ条

## 1. コンマを軽く扱わない

- John didn't die happily.
  - ジョンは幸せには死ななかった = 不幸な死に方をした
- John didn't die, happily.
  - ジョンは幸せにも死ななかった = 嬉しいことに死ななかった

## 2. 強調する場合はイタリックを用いる

- It is wrong.
  - (あることを指して)それは間違っている = 通常の意味
- *It* is wrong.
  - 間違っているのはそのことで、他のことではない = it を強調
- "It" is wrong.
  - "it"という言葉は(用法などが)間違っている
- IT is wrong.
  - IT(情報工学)は(道徳的に)

## 3. アプストロフィは「の」の意味だけではない

three I's の３通りの意味

- 3つの「私」という言葉
- 3つの「I」という文字
- 3つの「I」から始まる言葉
